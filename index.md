## English

**Daily Cloud Video** is an Android app that automatically backs up videos from your device to cloud storage that you set up and manage yourself.

The app provides the client application only. You build and manage the cloud environment used as the backend.

### Main features

- **Automatic video backup** — Automatically upload videos when connected to Wi-Fi
- **Your own cloud** — Use a cloud environment that you set up and manage
- **Multi-cloud support** — Designed for AWS, Google Cloud, and Microsoft Azure environments
- **Import** — Import videos stored in the cloud to another device
- **Labels** — Organize and find videos using labels
- **Sharing** — Share videos with other users in the same cloud environment by label

Sample setup guides for several cloud providers are available in the infrastructure repository:
- [https://github.com/daily-cloud-app/video](https://github.com/daily-cloud-app/video)

### Getting started

1. Prepare a supported cloud environment.
2. Open Daily Cloud Video and configure the endpoint for your environment.
3. Sign in with your account.
4. Allow access to videos when requested.
5. The app can then back up your videos to your cloud environment.

## 日本語

**Daily Cloud Video** は、端末の動画を自分で用意・管理するクラウド環境へ自動バックアップするAndroidアプリです。

このアプリはクライアントアプリのみを提供します。バックエンドとなるクラウド環境は、利用者自身で構築・管理します。

### 主な機能

- **動画の自動バックアップ** — Wi-Fi接続時に動画を自動アップロード
- **自分のクラウドを利用** — 自分で構築・管理するクラウド環境へ保存
- **マルチクラウド対応** — AWS、Google Cloud、Microsoft Azure環境での利用を想定
- **インポート** — クラウド上の動画を別の端末へ取り込み
- **ラベル** — ラベルを使って動画を整理・検索
- **共有** — 同じクラウド内の他のユーザーとラベル単位で動画を共有

いくつかのクラウドプロバイダー向けに、サンプルの環境構築手順を公開しています。
- [https://github.com/daily-cloud-app/video](https://github.com/daily-cloud-app/video)

### 使い方

1. 対応するクラウド環境を用意します。
2. Daily Cloud Videoを開き、構築した環境のエンドポイントを設定します。
3. アカウントでサインインします。
4. 必要に応じて動画へのアクセスを許可します。
5. 端末の動画を自分のクラウド環境へバックアップできます。
